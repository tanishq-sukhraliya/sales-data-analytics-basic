# Sales Data Analysis

## Project Overview

This project analyzes sales data using Python, Pandas, and Matplotlib.

The analysis includes:
- Total Sales
- Average Sales
- Highest Sale
- Sales by Category
- Bar Chart Visualization

## Technologies Used

- Python
- Pandas
- Matplotlib
